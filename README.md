##  How I Learn

I follow a simple development cycle:

```text
Learn the Concept
       ↓

       ↓
Build It
       ↓
Make Mistakes
       ↓
Debug & Understand the Problem
       ↓
Fix It
       ↓
Improve the Implementation
```

I believe that understanding **why something works** is just as important as knowing **how to write it**.
